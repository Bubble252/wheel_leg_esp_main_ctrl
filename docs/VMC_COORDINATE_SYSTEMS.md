## 概述

VMC (Virtual Model Control) 是一种将复杂的多关节机器人控制简化为"虚拟弹簧-阻尼器"系统的方法。其核心思想是：

1. **定义虚拟力**: 在工作空间定义期望的虚拟力/力矩
2. **雅可比转换**: 通过雅可比矩阵将虚拟力转换为关节扭矩
3. **扭矩控制**: 将计算出的扭矩发送给电机

```
┌─────────────────────────────────────────────────────────────┐
│  目标状态    虚拟弹簧-阻尼器    虚拟力    雅可比^T    关节扭矩  │
│  (L, α)  →   F = K×e + D×ė  →   F    →   J^T×F   →   τ     │
└─────────────────────────────────────────────────────────────┘
```

本项目支持两种坐标系的 VMC 控制：
- **世界坐标系 (WORLD)**: 基于水平-垂直方向 (x-y)
- **机身坐标系 (BODY)**: 基于腿长-身体角度 (L-α)

## 坐标系定义

### 1. 世界坐标系 (WORLD Coordinate)

```
        ^ y (向上为正，离地高度)
        │
        │    机身
        │   ┌───┐
        │   │ ● │ ← 髋关节 (原点)
        │   └───┘
        │     \
        │      \  腿
        │       \
        │        ● 轮子
        │
   ─────┴────────────────→ x (向后为正)
       地面
```

- **原点**: **髋关节轴心** (机身与大腿的连接点)
- **x 轴**: 水平方向，向后为正
- **y 轴**: 垂直方向，向上为正 (表示离地高度)
- **特点**: 需要 IMU pitch 角度来计算，与地面参考系对齐

> ⚠️ **注意**: y 值表示的是**轮子相对髋关节的垂直距离**，不是机身离地高度。
> 机身离地高度 = y + 轮子半径

### 2. 机身坐标系 (BODY Coordinate)

```
             ● 髋关节 (原点)
             │
             │ α (身体角度，向前为正)
             │╲
             │ ╲
             │  ╲  L (腿长)
             │   ╲
             │    ╲
             │     ● 轮子
             ↓
        机身垂直向下
```

- **原点**: **髋关节轴心** (与世界坐标系相同)
- **L (腿长)**: 髋关节到轮子的直线距离
- **α (身体角度)**: 腿相对机身垂直向下的夹角，向前为正
- **特点**: 不需要 IMU 数据，与机身固连

> 💡 **两种坐标系的原点相同**，都是髋关节轴心，只是参考方向不同：
> - 世界坐标系: 以地面为参考 (垂直向上为 y 正方向)
> - 机身坐标系: 以机身为参考 (沿机身垂直向下为 α=0)

## 世界坐标系 VMC

### 运动学关系

```c
// 世界坐标系下的足端位置 (考虑机身 pitch)
// x, y 是轮子中心相对于髋关节原点的坐标

// θ1 定义: 大腿相对于 x 轴（水平向后）的夹角
//   θ1 = 0°:   大腿水平向后
//   θ1 = -90°: 大腿垂直向下 (正常站立状态)
//   θ1 > 0:    大腿在水平线以上 (不可能的姿态)

θ1_world = θ1_body + pitch   // 世界坐标系下的大腿角度
x = L1×cos(θ1_world) + L2×cos(θ1_world + θ2)  // 足端水平位置 (向后为正)
y = L1×sin(θ1_world) + L2×sin(θ1_world + θ2)  // 足端垂直位置 (向上为正，θ1=-90°时 y < 0)
```

```
         x (向后为正)
      ←─────────────────────●  髋关节 (原点)
                           ╱│
                          ╱ │
                    L1   ╱  │ θ1 (相对于 x 轴，向下为负)
                        ╱   │ θ1 = -90° 时大腿垂直向下
                       ●    │
                  膝关节 ╲   │
                          ╲ │
                      L2   ╲│
                            ● 轮子中心 (x, y)
                            │
                            ↓ y 负方向 (轮子在髋关节下方)
```

> 📐 **x, y 的含义**:
> - **x**: 轮子中心相对髋关节的**水平距离**（向后为正）
> - **y**: 轮子中心相对髋关节的**垂直距离**（向上为正，所以正常站立时 **y 为负值**）
> - 当腿完全伸直向下时 (θ1 = -90°): x = 0, y = -(L1 + L2) ≈ -0.24m

### 雅可比矩阵

根据运动学公式 x = L1×cos(θ1) + L2×cos(θ1+θ2), y = L1×sin(θ1) + L2×sin(θ1+θ2)：

```
       ┌ ∂x/∂θ1   ∂x/∂θ2 ┐   ┌ -L1×s1w - L2×s12w   -L2×s12w ┐
J_xy = │                  │ = │                              │
       └ ∂y/∂θ1   ∂y/∂θ2 ┘   └  L1×c1w + L2×c12w    L2×c12w ┘

其中: c1w = cos(θ1_world), s1w = sin(θ1_world), 
      c12w = cos(θ1_world + θ2), s12w = sin(θ1_world + θ2)
```

### 控制律

```
┌────────────────────────────────────────────────────────────┐
│  水平方向 (x): 纯速度控制                                    │
│  F_x = K_vx × (target_vx - current_vx)                     │
├────────────────────────────────────────────────────────────┤
│  垂直方向 (y): 弹簧-阻尼 + 重力补偿                          │
│  F_y = K_y × (target_y - current_y)                        │
│      + D_y × (target_vy - current_vy)                      │
│      + gravity_comp × m × g                                │
├────────────────────────────────────────────────────────────┤
│  关节扭矩:                                                  │
│  [τ_hip ]     T   [F_x]                                    │
│  [      ] = -J  × [   ]                                    │
│  [τ_knee]         [F_y]                                    │
└────────────────────────────────────────────────────────────┘
```

### 适用场景

- ✅ 需要精确控制离地高度
- ✅ 需要保持相对地面的垂直稳定
- ✅ 在斜坡上保持水平姿态
- ❌ 需要高精度 IMU
- ❌ 计算量稍大

## 机身坐标系 VMC

### 运动学关系

```c
// 机身坐标系下的状态 (不需要 pitch)
L = sqrt(L1² + L2² + 2×L1×L2×cos(θ2))  // 腿长 (余弦定理)
β = atan2(L2×sin(θ2), L1 + L2×cos(θ2)) // 小腿引起的角度偏移
α = θ1 + β                              // 身体角度
```

### 雅可比矩阵

```
        ┌ ∂L/∂θ1   ∂L/∂θ2 ┐   ┌    0        -L1×L2×sin(θ2)/L    ┐
J_Lα =  │                  │ = │                                  │
        └ ∂α/∂θ1   ∂α/∂θ2 ┘   └    1     L2×(L1×cos(θ2)+L2)/L²  ┘
```

### 控制律

```
┌────────────────────────────────────────────────────────────┐
│  腿长方向 (L): 弹簧-阻尼 + 重力补偿                          │
│  F_L = K_L × (target_L - current_L)                        │
│      + D_L × (target_dL - current_dL)                      │
│      + gravity_comp × m × g × cos(pitch + α)               │
├────────────────────────────────────────────────────────────┤
│  身体角度方向 (α): 弹簧-阻尼                                 │
│  F_α = K_α × (target_α - current_α)                        │
│      + D_α × (target_dα - current_dα)                      │
├────────────────────────────────────────────────────────────┤
│  关节扭矩:                                                  │
│  [τ_hip ]    T   [F_L]                                     │
│  [      ] = J  × [   ]                                     │
│  [τ_knee]        [F_α]                                     │
└────────────────────────────────────────────────────────────┘
```

### 重力补偿说明

```
        │ 重力 mg (垂直向下)
        ↓
        │
        │╲ α
        │ ╲
        │  ╲ 沿腿方向分量 = mg×cos(pitch+α)
        │   ↘
        │    ╲
```

当机身水平 (pitch=0) 且腿垂直 (α=0) 时，重力全部沿腿方向，补偿力最大。

### 适用场景

- ✅ 与现有位置控制逻辑一致 (都是 L-α)
- ✅ 不依赖 IMU 精度
- ✅ 计算简单高效
- ✅ 与 LQR 职责分离清晰
- ❌ 不直接控制相对地面的高度

## 两种坐标系的对比

| 特性 | 世界坐标系 (WORLD) | 机身坐标系 (BODY) |
|------|-------------------|------------------|
| **坐标定义** | x-y (水平-垂直) | L-α (腿长-角度) |
| **参考系** | 地面 | 机身 |
| **IMU 依赖** | 需要 pitch | 不需要 |
| **重力补偿** | 简单 (固定方向) | 需要角度修正 |
| **与 LQR 耦合** | 较强 | 较弱 |
| **计算复杂度** | 较高 | 较低 |
| **斜坡适应** | 好 | 一般 |
| **推荐场景** | 复杂地形 | 平地/轮腿机器人 |

### 控制架构对比

**世界坐标系架构**:
```
┌─────────────────────────────────────────────────┐
│                    VMC (x-y)                    │
│  ┌─────────────┐    ┌─────────────┐            │
│  │ 水平力 F_x  │    │ 垂直力 F_y  │            │
│  │ (速度控制)  │    │ (高度控制)  │            │
│  └─────────────┘    └─────────────┘            │
│           ↓              ↓                      │
│        ┌────────────────────┐                  │
│        │   J_cartesian^T    │                  │
│        └────────────────────┘                  │
│                 ↓                              │
│        ┌────────────────────┐                  │
│        │  τ_hip, τ_knee    │                  │
│        └────────────────────┘                  │
└─────────────────────────────────────────────────┘
```

**机身坐标系架构** (推荐):
```
┌─────────────────────────────────────────────────┐
│  LQR (水平平衡)         VMC (腿部控制)          │
│  ┌─────────────┐    ┌─────────────────────────┐│
│  │ 轮子扭矩    │    │  ┌───────┐  ┌───────┐  ││
│  │ (pitch/速度)│    │  │ F_L   │  │ F_α   │  ││
│  └─────────────┘    │  │(腿长) │  │(角度) │  ││
│                      │  └───────┘  └───────┘  ││
│                      │       ↓         ↓       ││
│                      │  ┌─────────────────┐   ││
│                      │  │ J_workspace^T   │   ││
│                      │  └─────────────────┘   ││
│                      │          ↓              ││
│                      │  ┌─────────────────┐   ││
│                      │  │ τ_hip, τ_knee  │   ││
│                      │  └─────────────────┘   ││
│                      └─────────────────────────┘│
└─────────────────────────────────────────────────┘
```

## 参数调节指南

### 世界坐标系参数

| 参数 | 符号 | 默认值 | 单位 | 说明 |
|------|-----|-------|------|------|
| 水平速度增益 | K_vx | 50 | N·s/m | 越大水平响应越快 |
| 垂直刚度 | K_y | 1000 | N/m | 越大高度保持越好 |
| 垂直阻尼 | D_y | 50 | N·s/m | 抑制垂直振荡 |

### 机身坐标系参数

| 参数 | 符号 | 默认值 | 单位 | 说明 |
|------|-----|-------|------|------|
| 腿长刚度 | K_L | 1000 | N/m | 越大腿长保持越好 |
| 腿长阻尼 | D_L | 50 | N·s/m | 抑制腿长振荡 |
| 角度刚度 | K_α | 5 | N·m/rad | 越大角度保持越好 |
| 角度阻尼 | D_α | 0.5 | N·m·s/rad | 抑制角度振荡 |

### 通用参数

| 参数 | 符号 | 默认值 | 单位 | 说明 |
|------|-----|-------|------|------|
| 重力补偿系数 | gc | 0.5 | - | 0~1, 建议从小开始调 |
| 机器人质量 | mass | 3.0 | kg | 用于重力补偿计算 |
| 最大髋扭矩 | - | 5.0 | N·m | 安全限幅 |
| 最大膝扭矩 | - | 8.0 | N·m | 安全限幅 |

### 调参步骤

1. **先调重力补偿**:
   - 关闭 K 和 D
   - 调整 gc 使腿能勉强支撑自重

2. **再调刚度 K**:
   - 从小值开始 (100~500)
   - 逐渐增大直到响应满意
   - 如果振荡，说明太大

3. **最后调阻尼 D**:
   - 从小值开始 (10~30)
   - 增大直到振荡消失
   - 过大会使响应变慢

4. **预设模式**:
   - **Soft (软)**: K_L=500, D_L=30 - 适合缓冲冲击
   - **Stiff (硬)**: K_L=2000, D_L=80 - 适合快速响应

## 代码实现

### CLI 命令

```bash
# 坐标系切换
balance vmc coord world   # 切换到世界坐标系
balance vmc coord body    # 切换到机身坐标系

# 世界坐标系参数
balance vmc kvx 50        # 水平速度增益
balance vmc ky 1000       # 垂直刚度
balance vmc dy 50         # 垂直阻尼

# 机身坐标系参数
balance vmc kl 1000       # 腿长刚度
balance vmc dl 50         # 腿长阻尼
balance vmc ka 5          # 角度刚度
balance vmc da 0.5        # 角度阻尼

# 通用参数
balance vmc gc 0.5        # 重力补偿
balance vmc mass 3.0      # 质量

# 预设
balance vmc soft          # 软模式
balance vmc stiff         # 硬模式

# 查看状态
balance vmc status        # 显示所有参数
```

### 核心函数调用

```c
// 1. 初始化参数
vmc_params_t params;
vmc_get_default_params(&params);
params.coord_type = VMC_COORD_BODY;  // 选择坐标系

// 2. 填充输入
vmc_ctrl_input_t input = {
    .sensor = { .hip_angle = ..., .knee_angle = ..., ... },
    .pitch_deg = imu_pitch,
    .pitch_rate_deg = imu_pitch_rate,
    .target_leg_length = 0.20f,
    .target_body_angle_deg = 0.0f,
    ...
};

// 3. 计算
vmc_ctrl_output_t output;
vmc_ctrl_compute(&params, &input, is_left, &output);

// 4. 使用输出
motor_set_torque(HIP_MOTOR, output.hip_torque);
motor_set_torque(KNEE_MOTOR, output.knee_torque);
```

## 附录: 数学推导

### 余弦定理求腿长

```
     L1
  θ1 ●────────● 
     │        │
     │        │ L2
     │        │
     └────────● 轮子
         L

L² = L1² + L2² - 2×L1×L2×cos(π - θ2)
   = L1² + L2² + 2×L1×L2×cos(θ2)
L  = sqrt(L1² + L2² + 2×L1×L2×cos(θ2))
```

### 雅可比矩阵推导

对于机身坐标系:
```
L = sqrt(L1² + L2² + 2×L1×L2×cos(θ2))

∂L/∂θ1 = 0  (腿长与大腿角度无关)

∂L/∂θ2 = (1/2) × (2×L1×L2×(-sin(θ2))) / L
       = -L1×L2×sin(θ2) / L
```

```
α = θ1 + β, 其中 β = atan2(L2×sin(θ2), L1 + L2×cos(θ2))

∂α/∂θ1 = 1

∂α/∂θ2 = ∂β/∂θ2 = L2×(L1×cos(θ2) + L2) / L²
```
